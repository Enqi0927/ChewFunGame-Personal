# ChewFun Cooking Adventure 🍜🎮

**ChewFun Cooking Adventure** is a 2D platformer Java game developed as part of my university coursework at City, University of London.  
In this game, the player navigates through multiple kitchen-themed levels, collects recipes and items, avoids kitchen hazards, and defeats enemies like angry peanuts, mice, and blenders.

---

## 🌟 Features

- 🧑‍🍳 **Multiple Levels**: Three unique levels, each with different layouts and challenges  
- 🥤 **Item Collection**: Pick up Energy Drinks and Beef Noodles to progress  
- 🧠 **Object-Oriented Design**: Player, Enemy, Item, and Level classes with inheritance  
- 🐭 **Enemy Interactions**: Collision logic that reduces lives and adds difficulty  
- 🎉 **Victory Screen**: Displays a message when the player completes the game  
- 💡 **Time Complexity Comments**: Each method includes explanatory comments for learning clarity

---

## 🎮 Controls

- **Arrow keys**: Move left/right  
- **Spacebar**: Jump  
- **Collect items** and avoid enemies to proceed to the next level

---

## 🧱 Technologies

- Language: **Java**  
- Framework: **city.cs.engine** (game physics and rendering)  
- IDE: **IntelliJ IDEA / VS Code**

---

## 🔍 Learning Highlights

- Practiced principles of object-oriented programming and modular code structure  
- Implemented real-time event handling and sprite-based interactions  
- Improved code readability with time complexity annotations  
- Balanced code correctness with gameplay creativity
